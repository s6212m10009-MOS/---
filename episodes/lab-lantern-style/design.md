# สไตล์ "ตะเกียง · หนังเงา · เข็มทิศหลักฐาน"

สไตล์ภาพประจำช่อง เล่าไม่รู้บ้าง...รู้บ้าง ต้นแบบอยู่ที่ `episodes/lab-lantern-style/index.html`
แนวตั้ง 1080×1920 · 30fps · ใช้กับตอนสั้นและตอนยาวได้

## แนวคิดเดียว
ทั้งเรื่องเกิดบนผนังกระดาษเก่าแผ่นเดียว ส่องด้วยตะเกียงของมาสคอต
**ระดับแสงบอกระดับหลักฐาน** คนดูเห็นชัดเท่าที่หลักฐานมี

| สถานะ | แสง (`--lr` / `--dim`) | เงาหุ่น | เข็มทิศ |
|---|---|---|---|
| หลักฐานยืนยัน | กว้าง 800–900px / 0 | คม (`#soft` 1.4px) นิ่ง | เหนือ 🟢 #74C79A |
| ข้อสันนิษฐาน | กลาง 560px / 0.2 | คม ขยับเล็กน้อย | ตะวันออก 🟠 #F0B456 |
| ตำนาน | แคบ 450px / 0.35–0.4 เปลวสั่นแรง | เบลอ (`#haze` 3.2px) โยก | ตะวันตก 🟣 #B3A4EC |
| ยังไม่มีคำตอบ | แคบมาก 300px / 0.5 | เห็นแค่ขอบ | ใต้ ⚪ #8D9BBA |

## สี (จาก brand kit เท่านั้น)
- ความมืด/เงา #050D1F · พื้นเข็มทิศ #0A1A3C
- ผนัง #F2E6C9 + noise สองชั้น (เม็ดละเอียด + คราบ)
- ทองตะเกียง #D9A53A · จุดโฟกัสเรืองแสงหนึ่งจุดต่อเฟรม #FFD45A
- ตัวอักษรรอง #A9B3C9

## ตัวอักษร
- ชื่อช่อง/หัวเรื่อง: Chonburi
- ซับไตเติล: Anuphan 700 · 52px · กึ่งกลาง · กว้างสุด 940px · y ≈ 1236
- คำสำคัญในซับใช้สีสถานะเดียวกับเข็มทิศ (ทอง = สมบัติ, เขียว = มีหลักฐาน, ม่วง = ตำนาน)

## องค์ประกอบประจำ
1. **แสงตะเกียง** — `#dark` (navy มี mask วงกลม) + `#warm` (multiply สีทองขอบแสง) อ่านค่า `--lx --ly --lr --fl --dim` จาก `#film` · เปลวสั่นด้วย `--fl` ทุก 0.12 วิ (seeded PRNG)
2. **หุ่นเงาหนังใหญ่** — สี #050D1F, ฉลุลายประจำยาม (`mask="url(#perf)"`), เส้นแกะสีกระดาษ, **มีไม้เชิดลงล่างจอเสมอ** · เข้า = โผล่จากล่างจอ (`y:+900–1400`, power3.out) · ออก = ถูกดึงลง (power2.in)
3. **เข็มทิศหลักฐาน** — กลางบน y 200–600 · ส่ายหาคำตอบก่อน แล้วหยุดด้วย back.out ตรงคำที่พากย์ตัดสิน + เสียงระฆัง · ป้ายสถานะใต้เข็มทิศ y 612
4. **รูกุญแจปิดฉาก** — ใช้เปลี่ยนยุค/เปลี่ยนสถานที่ และปิดท้ายคลิป · วงกลมกับขาต้องเป็นคนละ element (path เดียวกันจะหักล้างกันเป็นแถบมืด)
5. **มาสคอต** — ซ้ายล่าง (60, 1430) สูง 360px โยกเบา ๆ · มีแสงรอบตะเกียงในมือ

## จังหวะ
- เปิด: มืด 0.4 วิ → ตะเกียงติด → แสงขยายใน 1.3 วิ ก่อนเสียงพากย์คำแรก
- หนึ่งประโยค = หนึ่งท่าแสง (ขยาย/เลื่อน/หรี่) ไม่ตัดภาพ ใช้การเลื่อนแสงแทนการตัดต่อ
- เสียงกระแทก (จอบ/หุ่นโผล่/เข็มหยุด) ตรงกับเฟรม — เวลาอยู่ทั้งใน `index.html` และ `tools/make_sound.py`

## ห้าม
- ภาพดาวเทียมเป็นพื้นหลังทุกช็อต · การ์ดสี่เหลี่ยมกลางจอ · มาสคอตยืนนิ่ง
- ทองเรืองแสงมากกว่าหนึ่งจุดในเฟรม
- ภาพเลือดหรือน่ากลัวเกินไป · วาดพระมหากษัตริย์เป็นหุ่นเงา (ใช้สิ่งของแทน เช่น บัญชี เรือ ตรา)
- ใส่ป้าย "ภาพจำลอง" ทุกฉากที่เป็นภาพประกอบ
