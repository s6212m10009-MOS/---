# 019: ปู่โสมเฝ้าทรัพย์ ผีเฝ้ากรุที่คนไทยกลัว จริงหรือแค่เรื่องเล่า

- **รูปแบบ:** เล่าตามโครงตอน 012 (เล่าตามลำดับ → ป้ายสถานะหลักฐาน → ปิดด้วยคำถาม A/B) · 94.5 วินาที แนวตั้ง 9:16
- **เสียง:** Gemini TTS (Sadaltager, สไตล์ผจญภัยลึกลับ) ผ่าน `make_voice_gemini.py` · **ซาวด์:** `tools/make_sound.py` กลองเร่งจังหวะ + ระนาดห้าเสียง + เอฟเฟกต์ขุดกรุ/คำสาป
- **ไฟล์:** `story.json` (สร้างจาก `tools/build_story.py`) · `narration.wav` · `timing.json` · `soundtrack.wav` (มิกซ์เสียงพากย์รวมแล้ว)
- **ยังไม่ได้เรนเดอร์วิดีโอ** (ต้องทำ index.html/data.js ก่อน)

## สถานะหลักฐาน (ป้ายบนจอ)
| ป้าย | เนื้อหา |
|---|---|
| ✅ หลักฐาน | กรุวัดราชบูรณะถูกลักลอบขุดราว พ.ศ. 2500–2501 ของที่ตามคืนได้เพียงส่วนหนึ่ง |
| ❓ เรื่องเล่า | พระแสงขรรค์ชัยศรีส่องแสง ผู้ร่วมขบวนการเสียสติ/ธุรกิจล้ม · เหตุการณ์พระองค์พีระที่วัดกุฎีดาว พ.ศ. 2503 (ผีไร้ศีรษะ) |
| ⚠️ ตีความ | นักวิชาการ (ม.รามคำแหง) ชี้ว่าไม่พบปู่โสมในรายชื่อผีของพระไอยการเบ็ดเสร็จ และขัดคติเถรวาท |

## Storyboard
hook (ขุดแล้วเป็นบ้า ร้านทองเจ๊ง) → what (ปู่โสมคือใคร) → heist (ขุดกรุวัดราชบูรณะ) → curse (เรื่องเล่าคำสาป) → prince (วัดกุฎีดาว 2503) → scholar (นักวิชาการ) → proof (พิสูจน์ได้/ไม่ได้) → ask (A ผีมีจริง / B เรื่องเล่า) → end
