# 012: สมบัติพระเจ้าตาก ขุมทรัพย์ใต้กรุงเก่าที่กลายเป็นชนวนล้มกรุงธนบุรี

- **เสาคอนเทนต์:** สมบัติและการค้นหา + ตำนานที่แยกด้วยหลักฐาน (ต่อจาก 001 ห้องอำพัน, 007 ทองยามาชิตะ, 009 กรุวัดราชบูรณะ)
- **ความยาว:** 99.2 วินาที แนวตั้ง 9:16, 30 fps
- **คำสัญญาต่อผู้ชม:** สมบัติใต้ดินที่เคยเลี้ยงคนทั้งแผ่นดิน กลายเป็นชนวนกบฏได้อย่างไร และเรื่อง "หนี้จีน 60,000 ตำลึง" จริงไหม
- **บทพากย์:** `story.json` (ซับ, คำอ่าน) → `narration-th.txt` · แหล่งข้อมูล: `sources.md`

## สถานะหลักฐาน (ป้ายบนจอ)

| ป้าย | ใช้กับ |
|---|---|
| ✅ หลักฐาน | ภาคหลวงขุดทรัพย์ใช้เลี้ยงคน/ซื้อเสบียง, พระวิชิตณรงค์ผูกขาดเร่งเงิน, ขุนแก้วกับกำนันบุกบ้านผู้รักษากรุง, พระยาสรรค์เปลี่ยนข้าง, เลิกภาคหลวงในรัชกาลที่ 1 (พระราชวิจารณ์ ร.5) · นายบุนนากต้นคิด (พงศาวดารฉบับพระราชหัตถเลขา) |
| ⚠️ ตีความ | "ชนวน" ล้มกรุงธนบุรี (ไม่ฟันธงว่าเป็นต้นเหตุ เปิดเป็นคำถาม A/B) · ปี "ต้น พ.ศ. 2325" ตามการนับปัจจุบัน |
| ❓ เรื่องเล่า | กู้จีน 60,000 ตำลึงแล้วแกล้งเสียสติหนีหนี้ → หักล้างด้วยชิงสือลู่ (ผ่านศิลปวัฒนธรรม) |
| 🎨 ภาพจำลอง | ไห บัลลังก์ ตัวละคร เรือ ทั้งหมด ไม่มีภาพเหมือนบุคคลจริง |

## Storyboard

| ฉาก | บท (ย่อ) | ภาพ |
|---|---|---|
| hook | สมบัติไร้เจ้าของใต้กรุงเก่า เลี้ยงคนทั้งแผ่นดิน แล้วกลายเป็นชนวนล้มบัลลังก์ | ภาพตัดใต้ดิน ไหทองเรือง ชนวนลุกจากไหขึ้นไปบัลลังก์ แล้วบัลลังก์แตก จอสั่น |
| bury | 2310 ฝังเงินทองหนีศึก เจ้าของไม่กลับมา | ป้ายปี 2310 ไฟสงคราม คนขุดหลุมฝังไห แล้วจางเป็นเงา |
| rush | หลังสงคราม แห่กลับมาขุด | ซูมเกาะเมืองอยุธยา จุดขุดกะพริบ 11 จุด |
| famine | ธนบุรีข้าวยากหมากแพง ซื้อข้าวแจก | บินจากกรุงเก่าไปพระราชวังเดิม การ์ดกระสอบข้าว + ลูกศรราคาขึ้น |
| law | ทรัพย์ไร้เจ้าของเป็นของแผ่นดิน แบ่งภาคหลวง | แผนภาพไห → ผู้ขุด / ภาคหลวง → เลี้ยงคน ซื้อเสบียง |
| monopoly | พระวิชิตณรงค์ผูกขาด เร่งเงินตามจำนวน | ตราประทับ "ผูกขาด" เหรียญลอยเข้าหีบ เกจเร่งเงินเต็ม |
| revolt | ต้น 2325 นายบุนนาก + ขุนแก้ว บุกบ้านผู้รักษากรุง | ป้ายปี 2325 ฉากกลางคืน ฝูงชนถือคบเพลิง บ้านไฟลุก |
| turn | พระยาสรรค์เปลี่ยนข้าง ยกทัพบุกธนบุรี | ชิปขีดฆ่า "ไปปราบ" → "เข้าร่วมกบฏ" เส้นทัพแดง กรุงเก่า → ธนบุรี |
| monk | ไม่ทรงสู้ ออกผนวชที่วัดแจ้ง | ซูมวัดอรุณฯ ฉากรุ่งสาง ปรางค์ + จีวร |
| king | เจ้าพระยามหากษัตริย์ศึกกลับจากเขมร เป็นรัชกาลที่ 1 · พระเจ้าตากถูกสำเร็จโทษตามพงศาวดาร | ซูมออกทั้งภูมิภาค เส้นทองจากเขมร พรมแดนไทย-กัมพูชา |
| stop | ภาคหลวงขุดทรัพย์ถูกเลิกในรัชกาลที่ 1 | ตราประทับ "เลิก!" |
| myth | หนี้จีน 60,000 ตำลึง แกล้งเสียสติ | ฉากซีเปีย เรือสำเภา สมุดหนี้ ตรา "เรื่องเล่า" |
| truth | ชิงสือลู่: จีนเพิ่งรับรอง 2324 · ทูต 11 ลำ · ไม่มีหลักฐาน | การ์ด ✓ สองข้อ แล้วขีดฆ่า ✕ + ที่มา |
| ask | ต้นเหตุ หรือแค่ไม้ขีด A/B | ไหสมบัติ + ไม้ขีดจุดไฟ + "?" |
| end | โลโก้ → วนกลับฉากไหใต้ดิน | |

## ไฟล์/ขั้นตอนผลิต
1. `python tools/make_voice.py`: เสียงพากย์ + timing.json
2. `python tools/build_map.py`: ภาพดาวเทียม 4 ระดับ (ภูมิภาค → กรุงเก่า–ธนบุรี → เกาะเมืองอยุธยา → วัดอรุณฯ/พระราชวังเดิม)
3. `python tools/make_sound.py`: ดนตรีระนาดสังเคราะห์ + เสียงประกอบ + มิกซ์เสียงพากย์ → soundtrack.wav
4. `python tools/build_data.py` → data.js
5. `python tools/snap.py <เวลา...>`: ภาพตรวจ review/contact.jpg
6. `npx hyperframes render . -o taksin-treasure-final.mp4 -q standard`
